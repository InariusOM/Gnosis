# Gnosis quiz flow test (5 questions)

Run this on the updated app, then open Quiz and start a 5-question quiz.

1. **Confidence is optional:** without tapping Sure / Think so / Guess, choose an answer. It should respond and record the confidence as Guess.
2. **Feedback:** confirm the chosen option is marked green when right or red when wrong, the correct option is green, and the feedback panel shows the source note with its key phrase highlighted.
3. **Wrong-answer details:** on a wrong answer, confirm the comparison names the concept the chosen answer belongs to and offers “Add to my misconceptions.” Tap it and confirm it is saved.
4. **Advance:** tap Next for questions 1–4. Confirm each next question appears, and the answered choices cannot be changed. On question 5, confirm the button says Finish. On desktop, Enter should perform the same advance after an answer.
5. **Results and scheduling:** tap Finish. Confirm results show the score and missed questions. Tap “Retry only my misses” and confirm only missed questions start again. Check the concepts answered incorrectly are scheduled sooner.

Repeat a question with each confidence choice to confirm Sure / Think so / Guess remain selectable before answering.

## Stage 2 — due scheduling stays hidden

1. Open Today. Confirm there is a greeting, streak, and one large session button, with no due section or due count.
2. Open Library and a subject. Confirm neither subject cards nor subject headers show due counts.
3. Add/review concepts with different schedule dates. Start today’s session; it should begin with concepts selected by the existing schedule.

## Stage 3 — feel and focus

1. Start a Quiz question and a Today session. Confirm both enter focus mode with an exit X, and that exiting returns to the appropriate screen.
2. Answer one correctly and one incorrectly. Check the green mint/coral feedback, encouragement text, and that the screen stays tappable.
3. Open Settings. Confirm sound is off by default; toggle it on for a short synthesized tone, then off. Toggle Reduce motion and confirm effects soften. Also test with the phone’s Reduce Motion accessibility setting enabled.
4. Check Library cards, tabs, teach-back reveal, streak, and results animations. Verify text remains readable and all controls work while transitions run.
